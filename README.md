# Sayed Aabidali — Construction Site Management Portfolio

Portfolio for the Construction Site Management course (School of Civil Engineering, KLE Technological University):
one simulated project — a seven-block shopping mall on 8 acres — across six problem statements (PS1 group, PS2–PS6 individual).

- `index.html` — home page (Doodle Studio design)
- `work/ps1.html` … `work/ps6.html` — problem-statement sheets
- `assets/js/config.js` — name, USN, contact details (edit here)
- `images/` — portrait, PS1 photos and layouts, PS2–PS6 figures

Static site: deploy the repo root on Vercel or GitHub Pages (no build step).
